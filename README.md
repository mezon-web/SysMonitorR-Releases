# SysMonitorR

Windows 11向けの軽量な半透明リソースモニターです。CPU、メモリ、ディスク、GPU、VRAM、ネットワーク、温度、バッテリーを画面上の小さなバーで確認できます。

## ダウンロード

現在の正式版は **v1.2.10** です。

- [SysMonitorR-v1.2.10.zip をダウンロード](https://github.com/mezon-web/SysMonitorR-Releases/releases/download/v1.2.10/SysMonitorR-v1.2.10.zip)
- [SHA-256確認用ファイル](https://github.com/mezon-web/SysMonitorR-Releases/releases/download/v1.2.10/SysMonitorR-v1.2.10.zip.sha256.txt)
- [最新リリース](https://github.com/mezon-web/SysMonitorR-Releases/releases/latest)

## 起動方法

1. ZIPをダウンロードし、書き込み可能なフォルダに展開します。
2. 展開された `SysMonitorR-v1.2.10` フォルダ内の `SysMonitorR.exe` を起動します。
3. オーバーレイの右クリック、またはタスクトレイのアイコンから設定を開きます。

日本語版Windows 11のx64環境向けです。.NET Desktop Runtimeの追加インストールは不要です。ZIPには `SysMonitorR.exe` とこの `README.md` だけを収録しています。

初回起動時に、実行ファイルと同じフォルダへ個人設定の `settings.json` を作成します。更新時はSysMonitorRを終了してから実行ファイルを置き換え、設定を引き継ぐ場合は `settings.json` を残してください。

Windowsサインイン時の自動起動機能は、インストーラー未提供のため一時的に無効化しています。アプリから自動起動の登録は行いません。

## 使い方

- オーバーレイを左ドラッグすると移動できます。
- 位置を見失った場合は、トレイの「位置を戻す」で主画面へ戻せます。
- 通常ウィンドウの背面へ回った場合は、最前面指定がONのままでも実際の重なりを検知し、約1秒ごとに確認してフォーカスを奪わず自動復旧します。
- 設定の「表示する項目」で、項目の表示・非表示を切り替えられます。左の `☰` をドラッグすると表示順を変更できます。ネットワークの受信・送信は1組として並び替えます。
- フォント、行間、バーの長さ・太さ、配色、背景の透明度を調整できます。Shift＋左ドラッグでもバーの長さと行間を調整できます。
- 更新間隔は0.5秒、1秒、2秒から選択でき、数値とバーのアニメーションも切り替えられます。
- ネットワーク速度はビット・バイト表示を選択できます。移動平均は初期値5秒、バーの最低基準は初期値100 MB/sです。
- 右クリックメニューの「一定時間非表示」で、5分、15分、30分、1時間後に自動表示できます。トレイの「今すぐ表示」で解除できます。
- 通常の「非表示」は次回起動後も維持されますが、一時非表示は再起動すると解除されます。
- 閉じる操作では常駐を続けます。完全に終了する場合はメニューの「終了」を選びます。

## 計測について

CPU使用率、メモリ使用量、ディスク読み書き速度、GPU使用率、VRAM使用量、ネットワーク送受信、CPU／GPU温度、バッテリー残量を表示します。

取得できない温度や、バッテリーのないPCのバッテリー項目は自動的に隠れます。設定画面では取得できない項目も表示予約としてON/OFFできます。

準備中の項目は「準備中」、更新が止まった項目は「古い値」と表示します。数値や設定画面の項目へカーソルを合わせると、取得状況や最終成功時刻を確認できます。

CPU使用率はWindowsのProcessor Information全体Timeカウンターを使用します。取得に失敗した場合、64論理CPU以下では旧方式へ代替し、30秒間隔で主取得元の復旧を確認します。64論理CPU超では、一部プロセッサグループだけの値を全体値として表示しません。CPU使用率の取得に管理者権限や追加ドライバーは不要です。

Windowsの版や採取タイミングによりタスクマネージャーと差が出る場合があります。すべてのPCでの一致や、報告された大幅な過小表示の解消は確認できていません。

CPU温度を読み取るには、追加ソフト「PawnIO」が必要な場合があります。設定の「CPU温度の診断」から、取得状況や導入方法を確認できます。「PawnIOの導入方法（公式）」は公式サイトを開きます。インストールは公式サイトの案内に従って行ってください。

PawnIOを有効にする場合は、本アプリを管理者として起動してください。診断画面の「管理者として再起動」を押し、Windowsの確認画面で許可すると、設定を保存してSysMonitorRを起動し直します。キャンセルや起動失敗の場合は、今のSysMonitorRを使い続けられます。PawnIOをインストール・更新した後は、SysMonitorRを再起動してください。

診断画面の「再検出」で温度センサーを探し直せます。「生センサー／LHMレポートを表示」で詳細を表示し、「保存…」でテキストに保存できます。CPU温度は機器やドライバー、実行権限により取得できない場合があります。

ネットワークはWindowsが外向き通信の最適経路として選んだ1つのアダプターを計測します。有線・Wi-Fi・VPNなどの切り替えに追従します。VRAMはGPU Adapter MemoryカウンターとDXGIの総容量を使用します。

設定を保存できない場合は警告を一度表示し、現在の設定で動作を続けます。起動時には、必要なネイティブコンポーネントをWindowsの一時フォルダへ展開します。

壊れた設定は、同じフォルダの `settings.json.corrupt-日時-識別子.bak` に原本を退避してから復旧します。読取りや退避ができない場合、および未対応の形式や設定値が含まれる場合は、原本を保持し、その実行中は設定を保存しません。以前の設定は通常どおり引き継げます。

## ファイルの確認

ZIPとSHA-256確認用ファイルを同じフォルダへ保存し、PowerShellで次を実行します。

```powershell
Get-FileHash .\SysMonitorR-v1.2.10.zip -Algorithm SHA256
Get-Content .\SysMonitorR-v1.2.10.zip.sha256.txt
```

表示されたハッシュが一致することを確認してください。
